# Modern Music App UI

**Android UI Prototype · Jetpack Compose · Material Design**

A modern, high-fidelity music application UI built using **Jetpack Compose**.  
This project focuses on **UI/UX structure, layout scalability, and component reusability**, serving as a strong foundation or scaffold for a full-featured music streaming app.

> ⚠️ Note: This is a **UI-focused project**. Playback logic and backend integration are intentionally omitted to emphasize clean UI architecture and design patterns.

---

## ✨ Features
- Modern music app layout inspired by real-world streaming apps
- Reusable and modular **Jetpack Compose** components
- Material Design–based theming and typography
- Structured navigation and screen composition
- Scalable UI suitable for future feature integration

---

## 🧱 Tech Stack
- **Kotlin**
- **Jetpack Compose**
- **Material Design**
- **Android Studio**
- **Gradle**
